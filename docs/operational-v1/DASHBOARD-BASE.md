# صفحة لوحة التحكم الأساسية — دون منح بيانات

طلب النسخة التشغيلية يجعل صفحة اللوحة الأساسية متاحة لكل حساب عمل نشط. كانت المعالجة السابقة تعيد403 للصفحة كلها عند غياب view_dashboard أو حجب محتواها بإعداد open:false.

يبقى ذلك منعاً لجميع بيانات اللوحة وتفاصيلها، بينما تعيد الصفحة الأساسية غلافاً بلا محتوى: counts كلها null لا أصفار بديلة، وكل المصادر والفلاتر والمهام والأرصدة فارغة. الطلب الصريح لمصدر ما يبقى403. لا تُقرأ datasets وتقارير المالية في هذا الفرع، ولا تتغير صلاحية قائمة أو تقرير أو مستند أو دور أو شركة.

في الواجهة المركزية تظهر الصفحة الأساسية حتى للدور المخصص بلا view_dashboard، برسالة واضحة وزر تحديث فقط. لا تُجلب MyWork في الخلفية لمحتوى محجوب. اختيار العودة للوحة الأساسية بعد خطأ يتم صراحة ويزيل فلاتر العرض القديم، ولا يعرض مجاميع قديمة أو مختلقة. يبقى الحساب المعلق أو غير النشط خارج جلسات العمل وفق الحراس الأصلية؛ لا تتجاوز الصفحة بوابة الإجازة أو الحظر.

يبقى إعداد open التاريخي محفوظاً كما هو ويضيق المحتوى. عُدّلت تسميته في شاشة المراجعة إلى عرض المحتوى، مع توضيح إتاحة الصفحة الأساسية. منع مصادر البيانات والصلاحيات الدومينية وRLS كما هي.

نجحت7 حالات خادم (حالة الصفحة الجديدة مع اختبارات اللوحة والهيكل الأمنية الأصلية) وواجهة فعلية لدور مخصص بلا صلاحية البيانات مع قيد تاريخي، والمنع المباشر للمصادر، وعدم جلب مهام مخفية، وفشل API ثم عودة سليمة، وAR/EN وثلاثة عروض والقائمة بعد إعادة تحميل الهاتف. الصور والتجارب اصطناعية فقط؛ هذا البناء غير منشور.
