# Bounded original backup source inventory

The existing protected staging backup capture now validates its Storage key inventory before invoking pg_dump or downloading attachment bytes. The original bucket-coverage check remains first: missing/public application bucket or another nonempty unsupported bucket still refuses. Release/Owner approvals, read-only TLS source transaction, schema manifest checks and original backup encryption are unchanged.

Only grouped object count and UTF8 key-byte totals are read first. At most10000 source keys,2MiB of total key bytes and2048 bytes per key are accepted. If the aggregate budget cannot fit, no full key list is transferred. Otherwise the original key query is bounded at10001 and checked against exact count/bytes, valid unmodified UTF8, unique paths and the existing traversal rules. Any mismatch refuses the entire capture; no name is truncated, renamed, silently omitted or deleted. These are technical capture budgets, not an invented retention policy.

The original object capture helper uses the same inventory validation before reading its first object. Retained backup archive/metadata bytes remain excluded by the existing strict classification; unknown legacy backup-like files remain ordinary source files. No additional project/bucket access, scheduler, cleanup, restore or provider connection is added.

Eleven linked tests pass, including four new offline inventory cases and a native PostgreSQL repeatable-read/read-only snapshot test. A controlled insertion into the owned synthetic Storage catalogue after the aggregate read does not alter its existing snapshot's key list; the later row is present outside that transaction. Original bucket coverage, additional occupied-bucket refusal, source object budgets, no recursive archive reads and encrypted capture integrity remain tested. TypeScript/build and189 root cases pass. This does not measure historical hosted Egress, prove a hosted backup's availability or verify Auth/Storage restoration. No operating source was queried or changed.
