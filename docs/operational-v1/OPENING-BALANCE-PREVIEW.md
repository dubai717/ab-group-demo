# Opening source import preparation — original workbench, no financial writes

`opening-balance-import-preview.ts` prepares CSV/XLSX templates and a strictly read-only source review using the original ledger chart/period checks, exact money arithmetic and balanced-line validator. AED is fixed. Each company/date/source-reference group balances separately; one company's debit cannot offset another company's credit or a different source batch. Invalid and duplicate rows remain visible, and incomplete source groups are explicitly marked. Existing account/company mappings must already be valid; no account is created or matched by a similar name.

Two native cases cover both templates, balanced/unbalanced cross-company and cross-source groups, canonical numeric duplicates, wrong-company charts, zero/two-sided/negative amounts, incomplete groups, closed periods, original100-line journal limit,200-source-row cap, unresolved party/vehicle references, actual worker refusal and required READ ONLY / REPEATABLE READ. Journals, entries, invoices, receipts, grants and idempotency records remain unchanged. TypeScript passed after explicitly typing the BigInt group totals.

This is **not historical balance reconciliation**. Existing ledger balances have not been compared; party/vehicle references are not applied or inferred; receivables/investor/wallet/tax roles and correction policy require their original reconciliation paths. `canApply=false`, `canPost=false`, `recordsCreated=false`. The original financial import screen now opens the shared CSV/Excel preview dialog for actual Active Owner only. The registered template/preview APIs use a read-only repeatable-read transaction and do not cache uploaded financial contents in request_dedup. There is no /run route or runtime financial writer. View As and ordinary employee access are refused. Source groups show balance, difference, period and unresolved mapping; the original invoice import form remains intact. Names are used for known source company/accounts. An exported source report neutralizes spreadsheet formulas. PR115 is unchanged. No real financial file was read or imported.
