# تجديد مستند الموظف ومصدر تفويضه — غير منشور

المرجع: 4.b و6 و8. يستخدم التنفيذ سجلات المستندات والنسخ والاعتماد والأرشفة والمهام والتفويض الأصلية. لا يمنح صلاحيات ولا يعيد فتح مهام تاريخية مكتملة.

## سبب الخلل المثبت في قاعدة اصطناعية

أنشأ عامل المتابعة مهمة تجديد لمستند مقبل على الانتهاء، ثم اعتبر المستند القديم الساري دليلاً على اكتمالها في التشغيل نفسه. أثبت الاختبار الفعلي حالة Completed دون أي تجديد. ولأن هوية المصدر فريدة، لم تكن إعادة تشغيل المتابعة دليلاً على وجود مهمة جديدة صحيحة.

أصبح الإنجاز مرتبطاً برقم سجل المستند والموظف والشركة ونوع المستند ومفتاح المهمة الأصلي. لا يكفي مستند قديم سارٍ أو رفع نسخة بانتظار الاعتماد أو اعتماد صورة جديدة بنفس مدة الصلاحية. يلزم سجل أحدث معتمد ونظيف وفترة صلاحية ممتدة وفق البيانات الأصلية؛ تبقى النسخ التي لا تحمل انتهاء خاضعة لقواعد المستند الأصلية، دون استنتاج تاريخ. النسخة المؤرشفة لا تصلح دليلاً. المصدر القديم الناقص أو غير المتطابق لا يُعتمد تلقائياً.

يقرأ الفحص صف المصدر المحدد وآخر نسخة معتمدة من بياناتها الوصفية فقط، مع فحص أرشفتها عند توافر الجدول الأصلي؛ لا ينقل ملفات أو ciphertext أو جميع مستندات الموظف. لا يُسقط المستند المنتهي حقوق التحصيل أو الخدمات.

## التفويض المرتبط بالإجازة

قبل الإنشاء والتفعيل وإعادة المهام المفتوحة، يُقيّم النظام صلاحية الموظف المستهدف عبر السياسة الحالية. يجب أن يستطيع الوصول إلى ملف صاحب المستند وتحديثه وفق إجراء الرفع الأصلي؛ تحديث مستند الذات يظل خاضعاً للاستثناء الأصلي نفسه. لا تُنسخ صلاحية أو عضوية أو مرفق إلى البديل. سحب الصلاحية بعد إنشاء التفويض يوقف نقل المهمة عند التفعيل ويُبقيها للمراجعة.

أعيدت تسمية المساعد إلى delegatedTaskSourceReview لأنه يتحقق الآن من مصادر المستندات والمحادثات؛ لم تُضف مصادر مالية إلى القائمة المسموحة. رسائل رفض المصدر بالعربية والإنجليزية تبقي المدخلات ومرجع التتبع.

## الاختبارات وحدود الإثبات

`backend/tests/leave-document-source.test.ts` يغطي الإنشاء/سحب الصلاحية/التفعيل من APIs الأصلية، دون منح تلقائي، وتجديد الهوية والجواز، والنسخة غير المعتمدة، ونفس الصلاحية، ومفتاح مصدر خاطئ، وغياب المرجع القديم، ودليل التجديد الصحيح وإنجازاً واحداً، وبقاء الملفات القديمة. يغطي أيضاً الأرشفة وفك الأرشفة المنطقي في قاعدة اصطناعية باستخدام015_document_center.sql الأصلي؛ هذا ليس Reset أو استعادة نظام أو قاعدة تشغيل.

مجموعة الموارد البشرية/التفويض/العودة/المحادثات المترابطة اجتازت74 حالة بعد تنفيذ القراءة المحدودة، ثم اجتاز اختبار الأرشفة الجديد حالة إضافية مستقلة؛ لا تجمعها مع الأعداد السابقة المتداخلة. اختبارات الواجهة الأصلية تُنفذ عبرoperational-v1-suite.browser.cjs، وتضاف رحلة مصادر المستندات إلى الرحلات السابقة. توثق ACCEPTANCE.json النتيجة النهائية وعدد الرحلات.

أخطاء الاختبار السابقة محفوظة: أول فشل كشف الإغلاق المبكر؛ توقع اسم حدث خاطئ صُحح إلىsource_verified الموجود فعلياً؛ وانتظار إعادة تمكين الزر يراعي مهلة حارس الضغط المتكرر الأصلي دون تعطيله. لا استعادة أو تحديث تشغيل أو ترحيل تاريخي أو تعديل مالية أو PR115 أو نشر. تبقى بقية مصادر التفويض والتذكيرات الخارجية والقبول الشامل غير مكتملة.
