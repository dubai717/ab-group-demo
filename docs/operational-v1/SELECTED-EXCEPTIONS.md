# الإلغاء الانتقائي لإضافات الستاندرد

الافتراضي إبقاء كل الإضافات الفردية. بعد تصميم الستاندرد، تظهر أسماء الحسابات المتأثرة وإضافاتها في معاينة الأثر فقط. الإلغاء اختياري لكل منحة مباشرة، ويستلزم معاينة جديدة قبل تأكيد الحفظ؛ تغيير الاختيار أو فشل المعاينة يعطل التأكيد ويبقي المدخلات.

الخادم يربط السياسة والمعرفات المختارة وإصدار المصدر وتعديل الستاندرد ببصمة التأكيد. لا يقبل اختياراً مكرراً أو منحة لحساب خارج الستاندرد أو حساب المالك. وجود منح صادرة من الموظف إلى آخرين يستلزم مراجعة مستقلة؛ لا إلغاء متسلسل لصلاحيات غير مختارة. تبقى صلاحيات الدور الموروثة ونطاقات الشركات والوحدات واستثناءات الشركات والبنوك مستقلة.

`backend/review/security-role-exceptions.sql` إجراء مقترح للمراجعة، لم يطبق على قاعدة مستضافة ولم يضف لمسار الترحيلات. يراجع المالك النشط والمجموعة والعضوية والإصدار والمنح التابعة داخل المعاملة، ثم يعدل الستاندرد ويلغي الصفوف المحددة فقط بتاريخ إلغاء وسجل تدقيق. أي إخفاق يعيد المعاملة كاملة. الإزالة معطلة إذا لم يوجد هذا الإجراء؛ الحفظ مع الاحتفاظ بالإضافات يظل يستخدم الإجراء السابق. لا حذف لمنحة أو حساب أو أثر تاريخي.

عمليات تعديل الصلاحيات على الخادم تأخذ القفل نفسه قبل قراءة نموذج السلطة، بما فيها الطلبات ذات query string، لمنع منح مؤجلة باستخدام صلاحيات مصدر قديمة. تكرار الطلب يستخدم إيصال العملية الأصلي.

## التحقق

ثماني حالات خادم مركزة تشمل الاختبارات الأصلية للستاندرد والهيكل، إضافة إلى الاختيارات وإلغاء منحة واحدة وبقاء غير المختار والتراجع عند اختلاف الإصدار أو وجود منح تابعة أو غياب سلطة المالك. نجحت182 حالة ثابتة وTypeScript و14 رحلة واجهة كاملة، بينها الرحلة الجديدة بالعربية والإنجليزية وعلى1440/768/390 وفشل معاينة يحتفظ بالاختيار دون تغيير الحساب.

تعثر تشغيل سابق عند اختيار مهمة في رحلة الإجازة الأصلية؛ لم تثبت علة نهائية ولم يُحتسب نجاحاً. نجحت الرحلة منفردة ثم المجموعة كاملة. أضيف تحقق من PID الخاص ببيئة الإجازة قبل اعتماد جاهزيتها وتشخيص محدود لبيانات الاختبار عند الفشل. لا تخفيف assertion أو حد طلبات.

## المتبقي

المنع الفردي الموروث وإعادة ضبطه ومعاينة جميع المؤشرات والجداول والرسوم وتوريثها ذرياً والنطاق الجغرافي والقبول النهائي ليست مكتملة. هذه نواقص برمجية. SQL الأمني يتطلب المراجعة النهائية قبل تطبيقه؛ البناء والاختبارات هنا اصطناعية فقط. الحزمة غير جاهزة للنشر.
