## Existing functions reused

`marketing_contracts`, encrypted fleet terms, `marketing_allocations`, contracting-company links/events and original vehicle invoices/receipts are authoritative. Existing tasks, approval source endpoints, collection attempts, notifications/read receipts, customer/vehicle import jobs and private document scan/storage are reused. No numbered SQL migration, role/grant mutation, opening balance or historical financial import is introduced.

## Changes

- Replaced the vehicle-count/manual-vehicle-data wizard with a floating searchable checkbox picker for real registered vehicles. Plate, file, type, capacity/seats, company/status and conflicting contracts come from the existing register. Company is fixed to the contract's authorized company. Availability may be filtered to a requested operating interval; the server rechecks under resource/contract locks.
- Operating periods, explicit pricing units/rate, agreed driver/owner share, additional service and notes are stored per vehicle. Draft totals are calculated and the original single draft payment schedule updated only on explicit save; multi-payment drafts require a reviewed schedule amendment. Active additions require a NEW clean signed amendment and reason. Earlier vehicle prices, payment schedule entries and issued invoices remain unchanged. Daily vehicles retain the existing separate-contract rule.
- Unlink retains agreed terms, immutable events, previous allocations, invoice/collection history and vehicle-to-contract reverse lookup. Already elapsed occupancy stays reserved historically; a current allocation ends at unlink time, and a future allocation is cancelled. Detached terms cannot create new vehicle invoices.
- Company/contract profiles group identity, company/licence/contact data, contracts, operating vehicles, independent invoices/collections, attachments, agreed shares and action history using the existing movable/resizable windows. Agreed shares are explicitly NOT represented as proof of accrued or paid liabilities.
- Removed the entire My shortcuts section and its layout checkbox; retained its stored preference for compatibility. Existing navigation, pages, grants and KPI drilldowns remain available. Added real database-backed My tasks and decisions cards with exact drilldown lists, filters, original task/collection/decision actions and notification read state. Source decisions remain server-authorized; no extra approval workflow is created.
- Contact outcomes now include contacted/no answer/off/promise/more time/reported partial or full payment/escalation. Explicit 30-minute/hour/custom follow-up takes precedence over a default. The same original task is rescheduled with revision/audit; existing notification de-duplication suppresses superseded reminders. Payment claims never change invoice/payment balances or close a task.
- Added real import UI to customers and vehicles; operational Synthetic import buttons are removed. Bounded XLSX and MDB/ACCDB workers, source-table selection, detected relationships, automatic/manual mapping, preview/confirmation fingerprint, stop/skip/explicit-field-update policies, 25-row transactions, target revision rechecks, repeat-job detection, downloadable reports and private scanned document storage reuse the existing import tables and save validation paths. No financial history is imported.
- Templates are generated from the current product validation adapters and verified physical encrypted-storage schema. They document supported flattened fields in Arabic/English; encrypted profile properties cannot be inferred from SQL column names alone. All cells are text so phones/identities/plates retain leading zeros. Excel template is a real XLSX; Access template ZIP contains the field workbook and optional Access DDL, which the server never executes.
