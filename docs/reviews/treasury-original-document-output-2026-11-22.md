# تقارير مستندات الخزينة الأصلية — بناء فقط

## السبب والتعديل

كانت تقارير سندات الصرف والإيداعات والشيكات في شاشة التقارير الأصلية تنقل صفوف الجداول كاملة (مع إخفاء الحمولة المشفرة لاحقاً)، وتعرض أول أعمدة تقنية دون تسميات بشرية موحدة. أضيف عرض اختياري من نفس المصادر، وربطته شاشة التقارير القائمة؛ لم تُنشأ وحدة مالية أو صلاحية أو وثيقة جديدة.

- استعلامات محدودة للحقول اللازمة فقط، مع الشركة والفترة والعملة وحد أقصى20000؛ تجاوز الحد يُرفض بدلاً من تصدير جزئي مضلل. لا تحميل للحمولة المشفرة أو الحسابات البنكية أو المستندات الخاصة.
- التواريخ تحتفظ بمعيار التقرير الأصلي: تاريخ تسجيل سند الصرف، تاريخ الإيداع المدخل، وتاريخ استحقاق الشيك؛ لا إعادة تفسير تاريخ المستندات القديمة أو استنتاج تاريخ سداد.
- مبالغ المستندات كما هي بدقة المصدر. الإيداع غير المؤكد يحتفظ بمبلغ مؤكد مجهول، وليس صفراً أو مبلغ الإيداع المقترح. الحالات عربية/إنجليزية، والاعتماد والإصدار والتسليم والمقاصة لا تُعامل كتسوية بنكية.
- لا مجموع مدفوعات من المستندات المختلفة أو الملغاة أو غير المسواة، ولا يعتبر الإيداع تحصيلاً جديداً. لا قيد أو أثر مالي أو إقفال معتمد لمجرد التقرير.
- JSON القديم دون طلب العرض الاختياري يبقى كما هو. صلاحيات التقرير والتصدير والشركات مستقلة عن عرض المصدر؛ لا استعارة لصلاحية ledger_view ولا كشف رقم حساب بنكي. تبقى تقارير التجميع غير المدعومة مرفوضة.
- CSV وExcel والطباعة من آلية التصدير الأصلية، بجميع الصفوف المفلترة بعد حد الصفحة200، والأرقام قابلة للتصفية رقمياً. التقارير الحالية بالألوان والتصميم نفسه.

## القبول

-9/9 اختبارات مترابطة ناجحة (حالتان جديدتان)، بما فيها205 سندات، صلاحية تقرير دون عرض/تصدير، منع الشركة الأخرى، رفض العمود التقني والتجميع غير المدعوم، مبلغ مجهول، العملة، حماية صيغ Excel/CSV وعدم تغيير القيود أو العهد أو الصلاحيات.
- متصفح فعلي AR/EN للمصادر الثلاثة وثلاثة عروض شاشة، ستة ملفاتPDF فعلية وExcel، مع ثبات حالات السندات والإيداعات والقيود والمقبوضات.
-175 اختباراً ثابتاً، TypeScript وبناء دون اتصالات مزود ناجحة.
- أول انحدار PDF متعدد الصفحات تعذر بـChromium IO.read داخل مساحة مؤقتة ممتلئة، دون أخطاء صفحة أو فشل استجابة API؛ نجحت الاختبارات الثلاثة الأصلية كاملة لاحقاً داخل مساحة الذاكرة المعزولة: إخراج الأستاذ/الفواتير، التحصيل، والأقساط/التسويات مع PDF متعدد الصفحات. لا تغيير منطق مالي لمعالجة عائق الاختبار.
