# إصلاح اعتماد المطابقة الجزئية — بناء فقط

## السبب المثبت

فحص اعتماد كشف البطاقة الأصلي كان يطلب وجود سجل مطابقة لكل سطر فقط؛ بينما مسار المطابقة يسمح عمداً بتوزيع عدة مصروفات على السطر نفسه. اختبار قبل الإصلاح أثبت استجابة 200 لاعتماد سطر 100 درهم مع مصدر 30.001 فقط، بدلاً من رفضه بـ409. الاختبار محفوظ في `backend/tests/card-reconciliation.test.ts`، وسجل الإثبات المحلي `card-reconciliation-before-fix.log`.

## التصحيح

- جمع مصادر المطابقة الأصلية بدقة المحرك وإلزام مساواة كل سطر بالكامل، مع إعادة التحقق من البطاقة والعملة والتاريخ والاتجاه وحالة الدفع والقيد الأساسي وسلامة مستند الكشف. لا يكفي وجود جزء مطابق.
- مسار تفاصيل الكشف يعرض المبلغ المطابق وفرق المطابقة صراحة، دون إنشاء سجل أو قيد من العرض.
- تقرير المالك يعرض الجزء غير المطابق فعلياً؛ سطر 100 مع مطابق 30.001 يبقى ظاهراً بقيمة 69.999، ولا يُضاف هذا الفرق إلى ذمة المالك. استعلامات مجمعة في قاعدة البيانات، لا تحميل أرشيف مرفقات أو حلقات طلبات.
- سند تسوية الشركة للمالك ليس سداد الجهة المصدرة للبطاقة الشخصية. لا يظهر كمرشح لهذا الغرض، ويرفض الخادم ربطه. لا يمنع وجود سند التسوية الصحيح اعتماد مصروفات البطاقة الموجبة المطابقة بالفعل. مسار بطاقات الشركة السابق محتفظ بضوابطه.
- سجلات المطابقة والقيود التاريخية لا تُعدل أو تُحذف. يطبق التحقق عند محاولة اعتماد حالة Review فقط. لا مخطط جديد أو ترحيل أو Reset أو اتصال بـSupabase.

## القبول وحدوده

30 اختباراً مرتبطاً ناجحاً بعد الإصلاح الأول. ثم 5 حالات موسعة ناجحة تشمل تقرير الفرق الدقيق ودورة المالك الثلاثية الأصلية: سداد الشركة يغلق ذمتها لكنه لا يطابق ائتمان البنك المصدر، وإثبات سداد البطاقة لا ينشئ مصروفاً آخر. TypeScript و172 فحصاً ثابتاً والبناء المحمول ناجحة؛ المتصفح النهائي نجح: رفض الاعتماد الجزئي برسالة ومرجع تتبع مع بقاء التفاصيل، عرض الفرق، استكمال ثلاثة مصادر أصلية ثم الاعتماد، دون زيادة القيود أو السندات. العربية والإنجليزية وثلاثة مقاسات ناجحة. متصفح استيراد CSV/XLSX الأصلي نجح أيضاً.

القبول التراكمي **502 ناجحاً، صفر إخفاق** يخص حزمة استيراد الكشف المحفوظة `96a971d`، المطابقة تماماً للشجرة البعيدة `4edce3587798e9e1866ca452e885e85127ca4bd1` عند `b367f106ec82a1965a9090c23bb150b520c6d750`؛ لا ينسب إلى التغييرات اللاحقة دون إعادة قبولها.

ما زالت مطابقة إثبات سداد البنك المصدر عبر مصدر أصلي مؤكد، ورد المورد وتصنيف الائتمانات، تحتاج استكمالاً منفصلاً. لا يتم اختلاق حركة بنك أو سند تسوية لتجاوز هذه النواقص.
