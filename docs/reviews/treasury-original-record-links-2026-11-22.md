# فتح مصادر الخزينة الأصلية — بناء فقط

امتدت روابط المصادر الأصلية في التقارير القائمة إلى سند الصرف والإيداع، باستخدام عارض RecordLinks ومساراته الموجودة. لا مصدر موازٍ أو إجراء صرف/إيداع جديد.

- الصف يحمل مفتاحHMAC خاصاً بالنوع والمصدر والشركة والمستأجر، وخريطةJSON منفصلة لمعرف المصدر عند وجود صلاحية ledger_view للشركة الفعلية. ملفات التصدير لا تتضمن خريطة الروابط أو معرف المصدر.
- صلاحية ledger_report وحدها تسمح بالتقرير دون الرابط؛ محاولة فتح المصدر مباشرة دون عرض الشركة تُرفض. الصلاحيات المطلوبة للعرض والتصدير لم تتغير.
- العارض الأصلي يطلب لغة المستخدم لسند الصرف والإيداع، ويعرض حقائق المستند نفسها بعناوين بشرية. الإيداع بلا رقم مستند لا يُعرض برقمهUUID كأنه رقم مالي. JSON القديم دون خيار اللغة يحتفظ بصيغته.
- تبقى صلاحية العملية البنكية finance_view، والقيد المرحل يتطلب عرضاً وتقريراً كما كان. لا قراءة للحسابات أو فك حمولة المستندات أو فتح مرفقات لمجرد التقرير.
- حارس المصدر الموجود يحتفظ بهوية المستخدم والشركة واللغة ونسخة مدخلات التقرير؛ استجابة وصلت بعد تغيير فترة التقرير تسقط ولا تفتح نافذة قديمة.
- عرض أصل المستند لا يثبت استلام نقدي أو تسوية بنكية ولا يغيّر مستنداً أو قيداً؛ أثره تدقيق فتح للقراءة فقط كالمسار الأصلي.
