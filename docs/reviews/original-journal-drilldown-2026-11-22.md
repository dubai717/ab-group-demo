# E73 — فتح القيد الأصلي واستمرارية سياق المصدر

بناء فقط؛ لا نشر أو ترحيل أو تغيير أذونات أو قيود.

أضيف نوع القيد المرحل إلى رابط السجل الأصلي المشترك، دون إنشاء شاشة أستاذ أو دفتر مواز. يعيد الخادم رقم القيد وتاريخه وعملته وإجمالي طرفيه وجميع أسطره الأصلية بأرقام وأسماء الحسابات، مع عناوين عربية/إنجليزية. يلزم عرض الدفاتر والتقارير للشركة الفعلية. لا يعرض الحمولة المشفرة أو المصدر التقني أو بيانات البنك أو يفترض ضريبة أو تحصيلاً. تبقى صلاحيات الأنواع القديمة، ومنها العملية البنكية، كما كانت.

ورقة مصادر الضريبة الأصلية تفتح هذا المصدر من تفاصيل الصف. روابط البنك تظل خاضعة لحجب مصدرها القائم؛ تقرير ضريبي لا يمنح الوصول للبنك.

التحقق كشف أن CenterForms.api **يحمي بالفعل** تبديل المستخدم وCSRF ويرفض الرد القديم بـstaleSession؛ لم يثبت كشف بيانات بين المستخدمين. الاختبار أبقى هذا الحارس الأصلي وأكد403 للقارئ على عملية المالك. الإضافة تسقط الرد والخطأ المتقادمين بهدوء، وتضيف تحققاً من النافذة الأم واللغة وجيل الجلسة قبل فتح السجل، وتغلق النوافذ الأصلية عند الخروج. استدعاء reset اختياري للدالة نفسها أيضاً، لكي يبقى عميل مشترك أقدم مخزن مؤقتاً متوافقاً. لم تتغير CSP أو حماية الدخول.
