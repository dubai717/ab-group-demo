# استكمال عرض مصادر التقارير المالية الأصلية — بناء فقط

أصبحت أنواع التقارير21 في شاشة الإدارة المالية الحالية تدعم العرض البشري الاختياري وآلية التصدير الأصلية. أضيفت هنا البطاقات ومؤشرات الأحداث وروابط التحويلات بين الشركات والصناديق؛ لم تنشأ وحدة أو أدوار أو دفتر موازٍ. صيغAPI القديمة دون خيار العرض محفوظة.

- البطاقات: حقول الدفعة الأصلية واسم البطاقة فقط، وفصل تاريخ تسجيلها عن تاريخ الدفع. حجب بطاقة المالك الشخصية يعتمد الحارس الأصلي قبل العرض والملفات؛ لا نقل للحمولة المشفرة أو تفاصيل الحساب. مبلغ الدفعة ليس تلقائياً مصروفاً أو استردادVAT أو سداداً للمصدر أو تسوية للمالك.
- المؤشرات: نفس صلاحية ledger_audit القائمة لكل شركة، واسم الموظف المرتبط بالحدث وقيمته الأصلية، لا افتراض منفذ اتصال أو عملة. لا جمع لقيم القبض والتسليم والإيداع باعتبارها تحصيلات جديدة؛ هي أحداث قد تخص المال نفسه. الحدث المجهول يحتاج مراجعة دون تغيير السجل.
- التحويلات: الروابط القديمة مع سند الشركة المطابق فقط، مع حالة الربط وحالة السند منفصلتين. سند شركة أخرى لا يسرب مبلغه أو يفتح رابطاً؛ يبقى المبلغ مجهولاً للمراجعة دون إصلاح تلقائي. اسم الشركة المقابلة يحتاج صلاحية تقريرها، وفتح السند يتطلب عرض شركته. لا افتراض تسوية بنكية أو استبعاد في تجميع المجموعة؛ تسويات المصروفات المشتركة لها تقريرها الأصلي المستقل.
- الصناديق: نفس استعلام الأرصدة المعتمدة المحدود والمجمّع، ونفس حارس الصندوق الشخصي أو الإدارة/التدقيق. فرق السقف ليس إذن تغذية. الحالة الحالية لا تعيد بناء وجود الصندوق تاريخياً. لا دمج عملات أو عهد تحصيل أو شيكات أو سلف داخل رصيد الصندوق.

المصادر الثلاثة المقروءة مباشرة تطلب الأعمدة الضرورية فقط، بحد20000 ورفض النتيجة الأكبر بدلاً من اقتطاع تصدير. لا تغيّر فترات التصفية الأصلية أو الحسابات أو السياسة المحاسبية. مصدر الصناديق الأصلي يبقى كما هو. المبالغ رقمية وقابلة للتصفية والتصدير الكامل دون IDs أو حمولة مشفرة.
