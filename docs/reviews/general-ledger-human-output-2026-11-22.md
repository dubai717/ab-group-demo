بناء فقط؛ لا نشر أو قيد أو تعديل بيانات أو صلاحية.

امتد عرض human_statement_v1 القائم إلى الأستاذ العام واليومية في شاشة التقارير نفسها. يحافظ على كل مبلغ وتاريخ وحساب ومرجع أصلي، ويعرض أسماء الحسابات والشركات بدلاً من المعرفات التقنية. صافي السطر هو مدين ناقص دائن، وليس رصيداً افتتاحياً أو متحركاً مفترضاً. لا استبعاد لحسابات متبادلة في حركات اليومية؛ طلب التجميع غير المدعوم مرفوض، وتبقى سياسة التجميع الأصلية للقوائم الثلاث كما هي.

فتح الصف يعيد استخدام رابط القيد أو العملية الأصلية. ربط JV يحتاج صلاحية العرض والتقرير الأصلية؛ ربط عملية البنك يحتاج finance_view كما في مسارها القائم. تقرير الدفاتر لا يمنح صلاحية فتح مصدر أو تصدير إضافية. يحتفظ JSON بمفتاح صف مشتق غير كاشف للمصدر، ويعيد روابط المصدر للمخول فقط؛ لا تظهر المعرفات في الأعمدة أو الملفات. يحفظ رابط المصدر هوية التقرير والشركة والمستخدم واللغة ونسخة المدخلات بعد انتظار الخادم.

التصدير والطباعة يستخدمان كامل الصفوف المطابقة والفلاتر والأنواع الدقيقة، ولا يقتصران على صفحة200. API القديمة دون علم العرض الجديد لم تتغير. استعلام هذا العرض الجديد يقرأ الفترة المطلوبة فقط، بسقف10000 حركة، ولا ينقل حمولة القيد المشفرة أو مفتاح مصدره غير المستخدم، ولا يقرأ فهارس السندات وتوزيعات البطاقة عند عدم طلب فلتر بند. فلتر البند يحتفظ بمصدر الربط الأصلي. لا Polling أو اشتراك أو تنزيل سحابي أضيف.
