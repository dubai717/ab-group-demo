# عرض الذمم وعهد التحصيل الأصلية — بناء فقط

امتد عرض التقارير البشرية القائم إلى محرك الفواتير المرتبطة ومحرك حركات عهد التحصيل الأصليين؛ لا وحدة جديدة أو حساب أو قيد أو صلاحية أو نقل عهدة.

- الذمم: رقم الفاتورة والبند الأصليان، المخصص للسداد، التسويات غير النقدية، الرصيد القانوني والدفتري، والتأخر وعمره من المحرك الأصلي دون إعادة حساب. المخصص قد يكون تطبيق رصيد سابق وليس قبضاً جديداً. الرصيد الحالي ليس رصيداً تاريخياً حتى نهاية فترة التقرير؛ اختيار النهاية يحدد الفواتير المستحقة حتى ذلك التاريخ، كما في التقرير الأصلي. الحقوق المصنفة للمستثمر تبقى كذلك؛ لا افتراض ملكية التمويل لبقية الفواتير أو لذمم غير ممثلة بهذه الفواتير.
- عهدة التحصيل: رصيد الحركات حتى نهاية الفترة من المصدر الأصلي، ولا استعمال لتاريخ البداية كرصيد افتتاحي مفترض. اسم صاحب العهدة دون UUID، النقد والشيكات منفصلان ولا جمع عبر العملات. العملة الاختيارية تطبق في العرض البشري؛ JSON القديم يبقى كما كان.
- المستخدم العادي يرى عهدته فقط، والتدقيق القائم يتيح عهد الآخرين ضمن الشركة. طلب رصيد موظف آخر دون تدقيق مرفوض. صلاحية التقرير ليست صلاحية فتح أصل الفاتورة أو التصدير؛ روابط الفواتير عبر العارض الموجود تحفظ صلاحية الشركة المتعاقدة كذلك.
- ملفات العرض والطباعة وCSV وExcel تعتمد الأعمدة البشرية والأنواع الرقمية نفسها، ولا تحتوي معرفات الأشخاص أو الشركات أو خريطة الروابط. الاسم المفقود أو نوع العهدة غير المعروف يظل واضحاً ويطلب مراجعة المصدر.
