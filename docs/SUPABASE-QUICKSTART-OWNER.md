# إعداد Supabase التجريبي — المطلوب من المالك فقط

أُصلحت حالات المخطط الست بترحيل 008 جديد؛ الملفات السبعة السابقة محفوظة. هذه الخطوات لا تطلب شراء خدمة أو نشر الموقع أو دمج #10/#11.

1. افتح [Supabase Dashboard](https://supabase.com/dashboard)، وأنشئ مشروعاً جديداً باسم `ab-group-erp-test` ضمن مؤسسة **Free**. اختر المنطقة المناسبة واستخدم كلمة مرور قاعدة بيانات قوية. لا تفعّل خطة مدفوعة أو إضافات مدفوعة؛ إذا تطلبت الشاشة الدفع فتوقف.
2. من **Storage** أنشئ bucket باسم `ab-private-test`، واترك **Public bucket مغلقاً**. لا تضف سياسة تسمح بالرفع أو القراءة العامة.
3. جهّز القيم التالية في **أسرار بيئة العمل المحمية**، أو ملف محلي غير متعقب `backend/.env` إذا كنت تُعد الربط بنفسك. لا ترسلها في المحادثة أو GitHub:
   - `SUPABASE_URL`: رابط المشروع.
   - `SUPABASE_ANON_KEY`: مفتاح anon من **Settings → API Keys → Legacy keys**.
   - `SUPABASE_SERVICE_ROLE_KEY`: مفتاح service_role من القسم نفسه؛ سر خادمي فقط. لا تضعه في HTML أو JavaScript المتصفح.
   - `MIGRATION_DATABASE_URL`: رابط PostgreSQL الإداري من زر **Connect**، بكلمة المرور الصحيحة وTLS موثّق. استخدم Direct إن كان متاحاً، أو **Session pooler**؛ لا تختَر Transaction pooler للترحيلات. إذا كان حقل كلمة المرور في الرابط يحتوي رموزاً خاصة، استخدم URI encoding عند تركيب الرابط، ولا تنشر الرابط.
4. أرسل في المحادثة **رابط المشروع واسم مضيف الاتصال ومنفذه فقط** (دون كلمة المرور أو رابط قاعدة البيانات الكامل)، وأكد تجهيز الأسرار. إن لم تجد مكاناً محمياً لإدخالها، أخبرني بذلك دون إرسال القيم.

بعدها أستكمل إعداد مستخدم SQL محدود، وتطبيق الترحيلات، والتهيئة بحساب مالك وهمي وتجربة تسجيل الدخول والشركات والحسابات والمستخدمين، دون دمج أو نشر. لا تنشئ أدوار SQL أو مستخدمين تجريبيين يدوياً الآن؛ سأجهز ذلك عند توفر الاتصال. يلزم إتاحة HTTPS للمشروع واتصال TCP لقاعدة البيانات في إعدادات بيئة العمل؛ سنحدد الوجهات الدقيقة من المعلومات غير السرية أعلاه.

سأولّد مفاتيح تشفير البيانات والنسخ الاحتياطي داخل البيئة المحمية، منفصلة عن بيانات الاعتماد، ولا تحتاج إلى توليدها أو إرسالها الآن. لا تُدخل بيانات تشغيل حقيقية. المستندات تبقى في الحجر حتى إعداد فاحص ملفات فعلي؛ لا نعرض نجاح فحص أو استعادة كلمة مرور وهمياً.
